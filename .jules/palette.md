## 2024-07-12 - Accessibility improvement for #brick-2d
**Learning:** Found an accessibility issue where the main interactive brick element `#brick-2d` was just a `<div>`. Converting it to a semantic `<button>` and adding an `aria-label` ensures screen readers announce it properly. It's crucial to include explicit CSS resets when changing an element's type, as browsers inject default styles for buttons (like background, border, and padding) that will break the visual layout if the project lacks a global CSS reset. Adding `:focus-visible` outline makes it keyboard navigable without disrupting mouse interactions.
**Action:** Always prefer semantic HTML tags over generic `<div>` elements for interactive content. When converting existing non-semantic elements, remember to manually reset default browser styles if a global reset isn't present, and verify focus states.
