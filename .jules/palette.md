## 2026-07-20 - [Accessibility] Semantic Interactions and Screen Reader Feedback for Minigames
**Learning:** In interactive minigames using generic divs for clickable areas (like the 2D brick), converting them to semantic `<button>` elements immediately exposes them to keyboard navigation and screen readers. Additionally, dynamically updating text areas (like hit counters or status messages) requires `aria-live="polite"` so screen readers can naturally announce the updates without interrupting the user.
**Action:** When implementing custom interactive elements or status messages, always prefer semantic HTML (`<button>`) with appropriate labels (`aria-label`) and ensure dynamic text nodes are marked as live regions (`aria-live`). Ensure CSS resets are applied when converting to semantic elements to avoid visual regressions.
