## 2024-07-24 - Semantic HTML and aria-live without global resets
**Learning:** When converting non-semantic elements (like `div`) to semantic interactive elements (like `button`) in environments without a global CSS reset, explicit resets (`padding: 0; outline: none; background: transparent; border: none;`) must be applied to avoid visual regressions, but in this specific case, only `padding: 0` and `outline: none` were needed as background and border were custom. Additionally, dynamic updates like hit counters or messages must use `aria-live="polite"` so screen readers natively announce them.
**Action:** Always verify if a project uses a global reset before converting elements to semantic tags to avoid unintended default browser styling regressions. Ensure dynamic UI components have `aria-live` attributes.
