## 2026-11-03 - IntersectionObserver for Three.js\n**Learning:** Three.js requestAnimationFrame loops run continuously regardless of visibility, consuming significant CPU/GPU resources on scroll-heavy single-page applications without build steps. A native IntersectionObserver is an effective, dependency-free way to pause rendering when the canvas container leaves the viewport.\n**Action:** Always implement IntersectionObserver for WebGL/Three.js canvases in long scrollable pages to explicitly pause renderer.render() when off-screen.
